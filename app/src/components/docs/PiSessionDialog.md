# PiSessionDialog.vue

Компонент відображає діалогове вікно для взаємодії з AI-агентом `pi`. Він керує сесією чату, дозволяє вибирати моделі та відображає історію обміну повідомленнями.

## Поведінка
1. **Ініціалізація (`onShow`):** При появі діалогу історія чату очищається. Вибирається перша доступна модель. Поле вводу заповнюється стартовим промптом, якщо він наданий, або промптом, згенерованим на основі вхідних даних.
2. **Вибір моделі:** Користувач може вибрати модель з наданого списку. Зміна моделі не порушує контекст сесії, оскільки сесія прив'язана до ідентифікатора запису.
3. **Надсилання повідомлення (`send`):**
    * Коли користувач вводить текст та натискає Enter (або натискає кнопку "Надіслати"), текст додається до історії як повідомлення користувача.
    * Статус "думає" активується.
    * Викликається зовнішній агент `pi` з поточним текстом, обраною моделлю та ідентифікатором сесії.
    * Отриманий результат від агента додається до історії як повідомлення агента.
    * Статус "думає" деактивується.
    * Лог автоматично прокручується до нового повідомлення.
4. **Збереження аналізу:** Якщо компонент позначений як збережуваний (`saveable`), користувач може натиснути кнопку "Зберегти аналіз", що емітує подію з останнім текстом агента.

## Гарантії поведінки
* Сесія чату зберігає контекст незалежно від того, яка модель використовується для обробки конкретного повідомлення.
* Діалогове вікно завжди відображає поле вводу та кнопки дій, навіть при заповненій історії.
* Під час обробки запиту агент `pi` (стан `running` = true), поле вводу та кнопка "Надіслати" стають неактивними.
* При виникненні помилки під час взаємодії з агентом, ця помилка відображається в лозі як повідомлення агента з позначкою помилки.
