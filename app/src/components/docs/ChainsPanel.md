# ChainsPanel.vue

Компонент відображає аналітичний дашборд для ланцюжків (chains), зібраних з логів. Він надає загальну статистику, деталі за типами ланцюжків та список останніх виконаних ланцюжків.

## Поведінка
1.  **Ініціалізація:** Компонент відображає загальну статистику ланцюжків, якщо дані доступні.
2.  **Фільтрація за періодом:** Зміна вибору періоду (24h, 7d, все) оновлює агреговані дані, відображаючи статистику за обраний часовий діапазон.
3.  **Оновлення даних:** Виклик кнопки оновлення ініціює повторне завантаження списку ланцюжків та аналізів.
4.  **Відображення списку:** Якщо ланцюжки існують, відображається список, обмежений першими 100 записами.
5.  **Деталізація ланцюжка:** Натискання на елемент списку розгортає його, завантажуючи кроки ланцюжка (якщо вони ще не завантажені) та відображаючи їх у таблиці.
6.  **Аналіз ланцюжка:** Натискання на іконку аналізу викликає завантаження повних тіл кроків, збагачує їх та емітує подію `analyze` з даними для зовнішньої обробки.
7.  **Відображення відсутності даних:** Якщо ланцюжків немає, відображається повідомлення з інструкцією щодо генерації логів.

## Гарантії поведінки
*   Статистичні дані (загальні та за тип) завжди відображаються відповідно до обраного часового періоду.
*   Кроки ланцюжка завантажуються лише при розгортанні відповідного елемента, що забезпечує ліниве завантаження.
*   При виклику аналізу, кроки ланцюжка гарантовано завантажуються та збагачуються повними тілами, якщо це можливо.
*   При відсутності ланцюжків, компонент відображає інструкцію та будь-які повідомлення про помилки, отримані від джерела даних.
