# ChainsPanel.vue

Компонент відображає аналітику та список ланцюжків, зібраних з логів. Він дозволяє фільтрувати дані за часовими періодами та переглядати деталі кожного ланцюжка.

## Поведінка
1.  При ініціалізації компонент відображає загальну статистику ланцюжків, викликів та токенів.
2.  Відображається таблиця агрегованих даних за різними типами ланцюжків, якщо такі дані доступні.
3.  Відображається список ланцюжків, якщо вони існують.
4.  При натисканні на ланцюжок у списку, його деталі розгортаються, і кроки ланцюжка завантажуються та об'єднуються з проксі-логом.
5.  При натисканні на кнопку "Аналіз" для ланцюжка, компонент емітує подію з даними ланцюжка та його кроків для подальшої обробки.
6.  При натисканні на кнопку оновлення, компонент перезавантажує список ланцюжків та аналізів, а також скидає розгорнутий стан.
7.  Якщо ланцюжків немає, відображається повідомлення з інструкцією щодо їх появи.

## Гарантії поведінки
*   Відображення агрегатів залежить від наявності даних у внутрішньому стані.
*   Деталі ланцюжка (кроки) завантажуються лише при першому розгортанні або при виклику аналізу, щоб уникнути зайвих мережевих запитів.
*   Статистичні показники (загальні та за тип) оновлюються відповідно до обраного часового періоду.
*   Кнопка аналізу неактивна, якщо для ланцюжка невідомий робочий каталог.
