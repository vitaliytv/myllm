Цей компонент візуалізує деталі одного етапу в процесі ланцюгового виконання. Він представляє метадані етапу, виводить будь-які помилки та відображає обмін інформацією між користувачем та моделлю. Він також надає можливість копіювати зміст запитів та відповідей.

## Поведінка

1. Відображає заголовок, що ідентифікує поточний етап, його тип та джерело моделі (локальне або хмарне).
2. У разі виявлення помилки на етапі, відображає виділений червоний банер з описом цієї помилки.
3. Якщо повне тіло запиту/відповіді доступне, відображає спеціальне повідомлення про фіксацію повних даних.
4. Якщо вміст запиту чи відповіді не доступний, але спроба була зроблена, відображає попереджувальний банер з інструкцією щодо активації детального трекінгу.
5. Відображає всю історію промпта. Якщо повне тіло доступне, виводиться вміст із поля тіла; інакше — ітерується по чергах повідомлень, відображаючи роль та текст кожного виступу, кожен з яких підлягає копіюванню.
6. Відображає фінальну відповідь моделі. Якщо повне тіло доступне, виводиться вміст із поля тіла; інакше — відображається основний вміст відповіді, який також може бути скопійований.
7. Надає кнопку для закриття діалогового вікна.

## Гарантії поведінки

* При успішному натисканні на кнопку копіювання, система виводить користувачу підтвердження про скопіювання даних.
* Компонент завжди коректно відображає статус моделі (локальне/хмарне), якщо метадані етапу присутні.
* Форматування виводу тексту зберігає оригінальне форматування, включаючи переноси рядків, для забезпечення достовірності відображення даних моделі.
