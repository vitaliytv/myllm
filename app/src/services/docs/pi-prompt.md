# pi-prompt.js

## Огляд

Формує початкове повідомлення для pi-сесії, використовуючи дані одного запису історії проксі-запитів. Об'єднує контекст запиту (шлях, модель, статус, тривалість) з тілом запиту та відповіддю. Надає повний контекст для аналізу та ініціює задачу адаптації коду проєкту в поточній директорії.

## Поведінка

1. Формує текст першого повідомлення для pi-сесії.
2. Витягує метадані запису історії проксі-запитів (шлях, модель, статус, тривалість).
3. Об'єднує метадані у єдиний рядок.
4. Створює структуру повідомлення, яка містить:
    * Інструкцію щодо аналізу запиту та відповіді.
    * Тіло запиту.
    * Відповідь.
    * Задачу щодо адаптації коду проєкту в поточній директорії.
5. Повертає готовий текст повідомлення.

## Публічний API

buildAnalysisPrompt — створює початковий запит для аналізу одного проксі-запиту, включаючи його контекст (шлях, модель, статус, тривалість), вміст запиту та відповіді, а також завдання адаптації коду проєкту в поточній директорії.
