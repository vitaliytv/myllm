# chains.js

## Огляд

Модуль нормалізує сирі записи ланцюжка за допомогою `parseChainRecord` та кроки за допомогою `parseChainStep`. Він групує записи за кореляційними ідентифікаторами за допомогою `groupEntriesByCorrelation`. Далі, він збагачує кроки, приєднуючи до них відповідні запити через `joinStepsWithRequests` та тіла через `joinStepsWithBodies`. Нарешті, модуль обчислює агреговані метрики для аналізу ланцюжків за допомогою `chainAggregates`.

## Поведінка

parseChainRecord нормалізує сирий запис ланцюжка у структуру для відображення.
parseChainStep нормалізує сирий запис кроку ланцюжка у структуру для відображення.
groupEntriesByCorrelation групує записи історії за ідентифікатором кореляції, зберігаючи порядок.
joinStepsWithRequests приєднує кроки ланцюжка до локальних записів проксі, використовуючи ідентифікатор кореляції або хеш промпту.
joinStepsWithBodies приєднує повні тіла (промпт/відповідь) до кроків ланцюжка, використовуючи ідентифікатор кроку або хеш промпту.
chainAggregates обчислює метрики для аналітики ланцюжків за типом та юнітом, з можливістю фільтрації за часом.

## Публічний API

parseChainRecord — перетворює фінальний запис ланцюжка у формат, зручний для відображення.
parseChainStep — перетворює запис одного кроку ланцюжка для кожного виклику.
groupEntriesByCorrelation — збирає записи логу за ідентифікатором кореляції; записи без такого ідентифікатора формують окремі групи.
joinStepsWithRequests — об'єднує кроки ланцюжка з локальними записами проксі за ідентифікатором кореляції або хешем запиту.
joinStepsWithBodies — додає повні дані запиту/відповіді до кроків ланцюжка, використовуючи ідентифікатор кроку або хеш запиту, включаючи кроки, виконані в хмарі.
chainAggregates — обчислює метрики для аналітики за різними типами записів, включаючи елементи, що потребують негайної уваги, з урахуванням часового діапазону.
