## Огляд

Модуль забезпечує роботу з даними, що описують ланцюжки взаємодій. Він визначає, чи є модель локальною, нормалізує записи ланцюжків та кроки, а також обчислює агреговані метрики для аналізу ланцюжків.

## Поведінка

isLocalModel визначає, чи вказує модель у специфікації на локальний провайдер.
parseChainRecord нормалізує сирий запис ланцюжка у структуру для відображення.
parseChainStep нормалізує сирий запис кроку ланцюжка у структуру для відображення.
joinStepsWithBodies приєднує повні тіла (prompt/response) до кроків ланцюжка, використовуючи `chainStep` або `promptHash`.
chainAggregates обчислює метрики для аналітики ланцюжків, включаючи показники за типом ланцюжка та юнітами, з можливістю фільтрації за часом.

## Публічний API

isLocalModel — визначає, чи вказує конфігурація на локальну модель, для відображення в інтерфейсі.
parseChainRecord — перетворює фінальний запис ланцюжка у формат, зручний для відображення.
parseChainStep — стандартизує запис окремого кроку в ланцюжку.
joinStepsWithBodies — додає повні дані (запит/відповідь) до кроків ланцюжка, використовуючи дані з системи збору тіл.
chainAggregates — обчислює статистичні показники для аналітики, включаючи метрики за типами та одиниці виміру, з можливістю фільтрації за часом.
