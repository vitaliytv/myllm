## Огляд

Модуль надає функції для аналізу та агрегації даних, пов'язаних з процесом вирішення проблем. Він дозволяє визначати локальні моделі, парсити записи та кроки в ланцюжку вирішення, отримувати мітки для проблем та рішень, ідентифікувати зачеплені файли, а також збирати дані з послідовних кроків для формування загального уявлення про процес.

## Поведінка

isLocalModel визначає, чи вказує специфікація на локально зареєстровану модель.
parseChainRecord перетворює сирий запис ланцюжка у стандартизовану модель для відображення.
parseChainStep перетворює сирий запис окремого кроку ланцюжка у стандартизовану модель.
chainProblemLabel створює читабельний підпис проблеми ланцюжка на основі фінального запису.
chainResolutionLabel визначає підпис, що вказує, хто або що завершило ланцюжок.
chainTouchedFilesLabel генерує підпис, що описує змінені файли, пов'язані з ланцюжком.
joinStepsWithBodies додає повні дані про промпт та відповідь до кроків, використовуючи дані зі сховища body-capture.
chainAggregates обчислює аналітичні агрегати за типами ланцюжків та юнітами, з можливістю фільтрації за часом.

## Публічний API

isLocalModel — вказує, чи використовується локальна модель, виходячи з префікса провайдера; це легкий візуальний маркер в UI.
parseChainRecord — перетворює кінцевий запис ланцюжка (`kind:'chain'`) у формат, зручний для відображення.
parseChainStep — нормалізує детальний запис окремого кроку виконання у ланцюжку.
chainProblemLabel — створює підпис проблеми в ланцюжку, який деталізує кількість порушень, причини та приклад повідомлення.
chainResolutionLabel — визначає, хто закрив проблему в ланцюжку: автоматизований процес або конкретна модель.
chainTouchedFilesLabel — генерує список змінених файлів у ланцюжку, показуючи кількість у загальному вигляді, а фрагмент — як приклад.
joinStepsWithBodies — приєднує повний вміст (запит/відповідь) до кроків ланцюжка, незалежно від того, чи використовується локальний чи хмарний проксі.
chainAggregates — збирає аналітичні показники по типах ланцюжків та об'єкти, які вимагають негайної уваги, з можливістю фільтрації за часом.
