# chains.js

## Огляд

Модуль реалізує логіку парсингу та агрегації даних ланцюжків. Він нормалізує сирі записи ланцюжка за допомогою `parseChainRecord` та кроки за допомогою `parseChainStep`. Дані групуються за ідентифікатором кореляції за допомогою `groupEntriesByCorrelation`. Кроки з'єднуються з відповідними запитами за допомогою `joinStepsWithRequests`, а також обчислюються агреговані метрики для аналітики за допомогою `chainAggregates`.

## Поведінка

parseChainRecord нормалізує сирий запис ланцюжка у структуру для відображення.
parseChainStep нормалізує сирий запис кроку ланцюжка у структуру для відображення.
groupEntriesByCorrelation групує записи історії за `correlationId`, зберігаючи порядок.
joinStepsWithRequests приєднує кроки ланцюжка до відповідних записів історії проксі, використовуючи `correlationId` або `promptHash`.
chainAggregates обчислює метрики для аналітики ланцюжків за типом та юнітом, з можливістю фільтрації за часом.

## Публічний API

parseChainRecord — перетворює фінальний запис ланцюжка у формат, зручний для відображення.
parseChainStep — перетворює запис одного кроку ланцюжка, що фіксується за кожен виклик.
groupEntriesByCorrelation — збирає записи логу за унікальним ідентифікатором кореляції; записи без такого ідентифікатора отримують окрему групу.
joinStepsWithRequests — об'єднує кроки ланцюжка з відповідними записами проксі, використовуючи ідентифікатор кореляції або хеш запиту.
chainAggregates — обчислює метрики для аналізу, включаючи одиниці, що вимагають негайної уваги, з обмеженням за часовим діапазоном.
