# chain-analysis.js

## Огляд

Модуль визначає цільовий репозиторій, аналізуючи тип задачі ланцюжка, за допомогою функції `inferTargetRepo`. Він також генерує промпт для великої мовної моделі за допомогою функції `buildChainAnalysisPrompt`. Цей промпт містить таблицю кроків та інструкції для аналізу неефективності та пропозиції виправлень.

## Поведінка

inferTargetRepo визначає репозиторій-джерело інструмента на основі типу задачі ланцюжка.
buildChainAnalysisPrompt створює повний текст промпта для LLM-аналізу ланцюжка, включаючи таблицю кроків та інструкції для пошуку причин неефективності та пропозиції патчів.

## Публічний API

inferTargetRepo — визначає репозиторій-джерело на основі типу завдання ланцюжка.
buildChainAnalysisPrompt — створює запит для аналізу ланцюжка.
