# chain-analysis.js

## Огляд

Модуль визначає цільовий репозиторій для аналізу ланцюжка. Він також генерує детальний текст промпта для великої мовної моделі, який містить таблицю кроків та інструкції для виявлення неефективності.

## Поведінка

inferTargetRepo визначає репозиторій-джерело інструмента на основі типу задачі ланцюжка.
buildChainAnalysisPrompt створює повний текст промпта для LLM-аналізу ланцюжка, включаючи таблицю кроків та інструкції для виявлення неефективності.

## Публічний API

inferTargetRepo — визначає репозиторій-джерело на основі типу задачі ланцюжка.
buildChainAnalysisPrompt — створює запит для аналізу ланцюжка.
