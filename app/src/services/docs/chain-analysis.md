# chain-analysis.js

## Огляд

Модуль визначає цільовий репозиторій для інструмента на основі типу задачі ланцюжка. Він також генерує деталізований текстовий промпт для великої мовної моделі, який містить таблицю кроків та завдання для виявлення неефективності в ланцюжку.

## Поведінка

inferTargetRepo визначає репозиторій-джерело інструмента на основі типу задачі ланцюжка.
buildChainAnalysisPrompt будує повний текст промпта для LLM-аналізу ланцюжка, включаючи таблицю кроків та завдання для виявлення неефективності.

## Публічний API

inferTargetRepo — визначає репозиторій-джерело на основі типу задачі ланцюжка.
buildChainAnalysisPrompt — створює текстовий запит для аналізу ланцюжка.
