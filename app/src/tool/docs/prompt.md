## Огляд

Файл задає системний промпт (`systemPrompt`), що керує поведінкою локальної мовної моделі. Цей промпт формує роль моделі як текстового асистента для взаємодії з користувачем, забезпечуючи підтримку звичайної розмовної логіки.

## Поведінка

systemPrompt надає інструкції для локальної мовної моделі, визначаючи її роль як асистента в застосунку myllm — локальному моніторі черги omlx, з акцентом на звичайну розмову через локальну модель, оскільки інструменти в застосунку відсутні.
