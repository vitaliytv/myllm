## Огляд

Файл відповідає за ініціалізацію інтерактивного чат-агента MyLLM. Він дозволяє використовувати публічну функцію `useAgent` для запуску агента у локальному середовищі `omlx` з префіксом `myllm`. Агент отримує доступ до набору локальних інструментів та базового системного промпту.

## Поведінка

1. Викликає функцію `useAgent` для ініціалізації інтерактивного чат-агента MyLLM.
2. Агент використовує локальне середовище `omlx` із префіксом зберігання `myllm` для функціонування без зовнішніх доменних інструментів.
3. Агент отримує доступ до набору інструментів, визначених у каталозі, та до базового системного промпту для визначення його поведінки.
