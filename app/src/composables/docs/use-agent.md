## Огляд

Надає публічну функцію `useAgent` для роботи з ACP-агентами. Не записує дані у ФС або БД. Спирається на конфіг `settings.json`. Перехоплює помилки та не передає їх назовні.

## Поведінка

1. `useAgent` створює read-only шлюз до ACP-агентів для виконання задач у застосунку.
2. Шлюз використовує каталог доступних інструментів і робочу директорію користувача; якщо її визначення недоступне, безпечно застосовує поточну директорію.
3. Надає вибір між налаштованими агентами та рівнями моделей, зокрема автоматичним вибором моделі.
4. Для одного з агентів модель визначається конфігурацією `settings.json`.
5. Помилки обробляються у fail-safe режимі й не передаються назовні як винятки.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
