# use-pi-agent.js

## Огляд

Модуль відповідає за ініціалізацію та управління сесіями чату з агентом. Він забезпечує запуск агента через публічну функцію `usePiAgent`, вибір доступних моделей та відправку текстових запитів у задану сесію. Модуль не виконує операцій з файловою системою чи базами даних.

## Поведінка

1. Викликати `usePiAgent` для ініціалізації агента.
2. Викликати `loadModels` для отримання списку доступних моделей.
3. Викликати `send` для продовження сесії чату з `pi`, використовуючи задану робочу директорію, модель, ідентифікатор сесії та текст запиту.

## Публічний API

usePiAgent — збирає список доступних моделей з оточення та виконує один крок у сесії pi.
