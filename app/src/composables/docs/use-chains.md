# use-chains.js

## Огляд

Модуль відповідає за управління станом та завантаження даних, пов'язаних із ланцюжками LLM. Він надає публічну функцію `useChains` для взаємодії з ланцюжками. Дані про ланцюжки та їхні аналізи зчитуються із глобального трасування LLM. Модуль забезпечує кешування цих даних у межах одного прогону. Усі операції є read-only, що означає відсутність змін у стані ФС/БД. Модуль реалізований з механізмом fail-safe, що гарантує перехоплення помилок без викидання винятків назовні.

## Поведінка

1. При ініціалізації хука `useChains` виконується завантаження списку ланцюжків.
2. Завантажується список ланцюжків з глобального трасування LLM.
3. Список ланцюжків нормалізується та зберігається.
4. Завантажується індекс збережених аналізів для ланцюжків.
5. При виклику `load` список ланцюжків перезавантажується, а кеш кроків очищається.
6. При виклику `loadSteps` кроки для заданого ланцюжка завантажуються з глобального трасування LLM, якщо вони не знаходяться в кеші.
7. При виклику `loadAnalyses` індекс аналізів завантажується.
8. При виклику `loadBodies` повні тіла для заданого ланцюжка завантажуються з глобального трасування LLM.

## Публічний API

useChains — Завантажує та кешує список ланцюжків LLM-викликів з глобального трасування.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- Кешує результати в межах одного прогону.
