# use-chains.js

## Огляд

Управляє списком ланцюжків та індексом збережених аналізів. Забезпечує завантаження глобального списку ланцюжків через `useChains`. Дозволяє отримувати кроки для конкретного ланцюжка, використовуючи кешування для уникнення повторних викликів. Хук є лише для читання даних (read-only) і не здійснює записів у файлову систему чи базу даних.

## Поведінка

1. При ініціалізації хука `useChains` виконується завантаження списку ланцюжків та індексу збережених аналізів.
2. Завантаження списку ланцюжків виконується для отримання глобального списку ланцюжків.
3. При успішному завантаженні списку ланцюжків, кеш кроків ланцюжків очищається.
4. При виникненні помилки під час завантаження списку ланцюжків, ця помилка зберігається у стані.
5. Метод `load` виконує повторне завантаження списку ланцюжків.
6. Метод `loadSteps` повертає кроки для заданого ланцюжка, якщо вони вже знаходяться у кеші.
7. Метод `loadSteps` виконує виклик для отримання кроків ланцюжка, якщо вони відсутні в кеші, і зберігає їх у кеші.
8. Метод `loadAnalyses` виконує виклик для отримання індексу збережених аналізів.

## Публічний API

useChains — Завантажує список ланцюжків LLM-викликів із глобального трасування, кешуючи їх при першому використанні.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- Кешує результати в межах одного прогону.
