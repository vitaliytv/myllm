# use-chains.js

## Огляд

Модуль керує станом та кешуванням даних, пов'язаних із ланцюжками та їхніми аналізами. При ініціалізації модуль завантажує список ланцюжків та індекс збережених аналізів, використовуючи механізм `useChains`. Усі операції є лише для читання (Read-only). Модуль реалізує механізм fail-safe для перехоплення помилок, не викидаючи винятків назовні. Для забезпечення швидкого доступу до даних, модуль кешує кроки ланцюжків та повні тіла у межах поточного прогону.

## Поведінка

1. При ініціалізації `useChains` виконується завантаження списку ланцюжків та індексу збережених аналізів.
2. Завантаження списку ланцюжків виконується з можливістю перехоплення помилок, при цьому внутрішній стан помилки оновлюється, але виняток не викидається.
3. Завантаження індексу збережених аналізів виконується з можливістю перехоплення помилок, при цьому внутрішній стан аналізів ініціалізується порожнім списком у разі невдачі.
4. Виклик `load` перезавантажує список ланцюжків, очищаючи кеш кроків ланцюжків.
5. Виклик `loadSteps` повертає кроки для заданого ланцюжка, якщо вони вже знаходяться в кеші. Інакше, він виконує запит на отримання кроків, нормалізує їх та кешує.
6. Виклик `loadAnalyses` оновлює індекс збережених аналізів.
7. Виклик `loadBodies` отримує повні тіла для заданого ланцюжка, повертаючи порожній список у разі невдачі запиту.

## Публічний API

useChains — Завантажує та кешує список ланцюжків LLM-викликів із глобального трасування.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- Кешує результати в межах одного прогону.
