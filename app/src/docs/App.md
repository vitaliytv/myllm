# App.vue

Компонент є головним інтерфейсом застосунку, що відображає стан підключення до черги Omlx та надає панель керування. Він також відображає деталі активних моделей, їхній статус у черзі та історію всіх запитів, що проходили через локальний проксі.

## Поведінка
1. **Ініціалізація:** При завантаженні компонента перевіряє наявність API ключа у локальному сховищі. Якщо ключа немає, намагається отримати його з системних змінних середовища.
2. **Автоматичне підключення:** Якщо API ключ знайдено, компонент автоматично викликає функцію підключення та запуску проксі.
3. **Підключення:** При натисканні кнопки "Підключити" зберігає конфігурацію, підключається до черги Omlx за вказаними параметрами та запускає локальний проксі.
4. **Відключення:** При натисканні кнопки "Відключити" зупиняє локальний проксі та припиняє моніторинг черги.
5. **Відображення черги:** Якщо черга підключена, відображає список моделей, показуючи їхній статус (активні, у черзі), прогрес генерації та деталі поточних запитів.
6. **Відображення історії:** Відображає список усіх запитів, що пройшли через проксі. Кожен запис можна розгорнути для перегляду повного JSON-тіла запиту та відповіді.
7. **Керування історією:** Дозволяє користувачеві очистити історію запитів після підтвердження.
8. **Управління діалогами:** Дозволяє відкривати діалог для взаємодії з агентом та переглядати журнал запитів агента.

## Гарантії поведінки
* Статус підключення (підключено/відключено) відображається коректно на інтерфейсі.
* Локальний проксі активується лише після успішного підключення до черги.
* Історія запитів відображається хронологічно, і кожен запис містить повні дані запиту та відповіді.
* Функціональність підключення та відключення є атомарною: зупинка проксі відбувається перед припиненням моніторингу черги.
