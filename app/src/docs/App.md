# App.vue

Компонент є головним інтерфейсом застосунку, що відображає основні елементи навігації та інтегрує модулі для роботи з агентом, аудиту та аналізом ланцюжків. Він ініціалізує версію застосунку та завантажує моделі для агента.

## Поведінка
1. При завантаженні компонента:
    * Отримується та встановлюється версія застосунку.
    * Ініціалізуються моделі для агента.
2. При натисканні кнопки "Агент":
    * Відкривається діалогове вікно агента.
3. При натисканні кнопки "Журнал запитів агента":
    * Відкривається діалогове вікно аудиту.
4. При взаємодії з панеллю ланцюжків та виклику аналізу:
    * Якщо ланцюжок має робочу директорію (`cwd`) і моделі агента завантажені, ініціюється аналіз ланцюжка.
    * Створюється запис для аналізу з ідентифікатором та робочою директорією.
    * Генерується промпт для аналізу, що містить деталі ланцюжка та кроки.
    * Відкривається діалогове вікно для аналізу ланцюжка.
5. При збереженні результату аналізу ланцюжка:
    * Викликається системний виклик для збереження результату аналізу у визначену директорію.
    * Відображається сповіщення про успішне збереження.
    * Панель ланцюжків оновлюється.

## Гарантії поведінки
* Діалогові вікна агента та аудиту відображаються відповідно до стану змінної `agentOpen` та `auditOpen`.
* Аналіз ланцюжка ініціюється лише за умови наявності робочої директорії для ланцюжка та завантажених моделей агента.
* Збереження аналізу ланцюжка гарантує виклик системної функції з усіма необхідними метаданими ланцюжка та результатом аналізу.
