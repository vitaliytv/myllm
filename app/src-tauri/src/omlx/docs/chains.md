# chains.rs

## Огляд

Модуль забезпечує кореляцію викликів LLM-сервісів шляхом зчитування метаданих, які клієнт LLM-сервісу записує у глобальний trace-файл (`~/.n-cursor/llm-trace.jsonl`) через заголовки `x-chain-id`, `x-chain-step` та інші. Він обчислює 16-символьний хеш (`prompt_hash`) останнього повідомлення з `role=="user"`, використовуючи оригінальне тіло повідомлення до будь-якої компресії. Модуль надає функції для перегляду списку ланцюжків (`chains_list`), детальних кроків ланцюгів (`chain_steps`) та збереження аналізів (`save_chain_analysis`, `list_chain_analyses`). Усі операції реалізовані з механізмом fail-safe: при виникненні помилок модуль не кидає винятків назовні, а повертає порожнє значення.

## Поведінка

ChainCorrelation зберігає кореляційні дані запиту, включаючи ID ланцюжка, номер кроку, тип задачі, директорію виклику та хеш промпту.
prompt_hash обчислює 16-символьний хеш останнього повідомлення користувача з тіла запиту, використовуючи спільний контракт.
extract_correlation витягує кореляційні поля з заголовків запиту та обчислює хеш промпту з тіла запиту.
chains_list зчитує хвіст глобального trace-файлу та повертає список фінальних записів ланцюжків.
chain_steps зчитує хвіст глобального trace-файлу та повертає всі кроки, що належать до вказаного ID ланцюжка.
save_chain_analysis зберігає markdown-результат аналізу ланцюжка у файлі `.md` у директорії `~/.n-cursor/insights/` та оновлює індекс аналізів.
list_chain_analyses зчитує індекс збережених аналізів з `app-data` та повертає список метаданих.

## Публічний API

ChainCorrelation — Збирає кореляційні дані із заголовків запиту та хеш промпта як резерв.
prompt_hash — Генерує унікальний ідентифікатор для промпта.
extract_correlation — Витягує кореляційні дані із заголовків запиту та обчислює хеш промпта з його вмісту.
chains_list — Повертає список останніх завершених ланцюжків, відсортованих за часом.
chain_steps — Подає послідовність кроків, що складали один ланцюжок.
save_chain_analysis — Зберігає детальний аналіз ланцюжка у Markdown-файл та оновлює індекс аналізів.
list_chain_analyses — Повертає список усіх збережених аналізів для відображення в інтерфейсі.

## Гарантії поведінки

- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- За певних помилок повертає порожнє значення (напр. `null`) замість винятку.
