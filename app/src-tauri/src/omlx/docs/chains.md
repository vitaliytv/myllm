# chains.rs

## Огляд

Файл реалізує механізм для читання глобального трасування LLM-викликів, збереженого у `~/.n-cursor/llm-trace.jsonl`, на основі конфігурацій, визначених у `garbage.json`. Він дозволяє отримувати список завершених ланцюжків (`chains_list`), переглядати окремі кроки кожного ланцюжка (`chain_steps`) та зчитувати збережені тіла запитів (`read_body_capture`). Команди працюють виключно з глобальним trace-файлом, не залежно від локального проксі. Функціонал також включає збереження результатів аналізу ланцюжка у вигляді Markdown-файлу (`save_chain_analysis`) та індексування цих аналізів (`list_chain_analyses`). Усі операції реалізовані з механізмом fail-safe: перехоплення помилок відбувається без викидання винятків назовні, а при певних збоях повертається порожнє значення замість винятку.

## Поведінка

chains_list читає хвіст глобального trace-файлу та повертає список фінальних записів ланцюжків.
chain_steps читає хвіст глобального trace-файлу та повертає всі кроки, що належать до вказаного ідентифікатора ланцюжка.
read_body_capture зчитує всі JSON-тіла з директорії body-capture для заданого ідентифікатора ланцюжка та повертає їх у відсортованому порядку.
save_chain_analysis зберігає markdown-результат аналізу ланцюжка у файлі `.md` у директорії insights та додає запис в індекс `chain-analyses.jsonl`.
list_chain_analyses зчитує індекс збережених аналізів з app-data та повертає список цих записів.

## Публічний API

chains_list — Перераховує останні завершені ланцюжки, сортуючи їх за часом створення.
chain_steps — Виводить послідовність кроків, що складали один ланцюжок.
read_body_capture — Завантажує повні запити та відповіді для кожного кроку ланцюжка, якщо було увімкнено збір даних.
save_chain_analysis — Зберігає детальний аналіз ланцюжка у файлі Markdown та оновлює реєстр аналізів.
list_chain_analyses — Повертає список усіх збережених аналізів для відображення в інтерфейсі.

## Гарантії поведінки

- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- За певних помилок повертає порожнє значення (напр. `null`) замість винятку.
