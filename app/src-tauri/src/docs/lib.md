# lib.rs

## Огляд

Цей файл відповідає за ініціалізацію та запуск основного застосунку. Він налаштовує всі необхідні компоненти, включаючи плагіни для роботи з зовнішніми ресурсами, управління станом вікна та процесами. Запуск надає можливість взаємодії з функціоналом управління, проксі, ланцюжків аналізу та моделі агента.

## Поведінка

1. Запускає застосунок.
2. Ініціалізує плагіни для відкриття зовнішніх ресурсів, роботи з HTTP-запитами, агентами, оболонкою та управління станом.
3. Налаштовує обробник викликів для доступу до функціоналу управління, проксі, ланцюжків аналізу та моделі агента.
4. Додає плагіни для управління станом вікна та оновлення застосунку у режимі робочого столу.
5. Додає плагін для управління процесами.
6. Додає плагін для мосту MCP у режимі налагодження.
7. При запуску застосунку встановлює заголовок вікна з версією застосунку.
8. Запускає застосунок.
