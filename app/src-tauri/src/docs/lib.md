# lib.rs

## Огляд

Застосунок ініціалізує плагіни для роботи з зовнішніми ресурсами, HTTP-запитами, агентами та управління вікнами. Він реєструє обробники для керування списками, кроками ланцюжків, збереженням аналізів, читанням даних захоплення тіла, отриманням моделей та запуском агента Pi. Застосунок встановлює заголовок головного вікна з назвою та версією.

## Поведінка

1. Запускає застосунок.
2. Ініціалізує плагіни для відкриття зовнішніх ресурсів, роботи з HTTP-запитами, агентами, управління вікнами та шеллом.
3. Реєструє обробники викликів для функцій, що керують списками та кроками ланцюжків, збереженням аналізів ланцюжків, читанням даних захоплення тіла, отриманням моделей агента Pi та запуском агента Pi.
4. На робочому столі додає плагіни для стану вікна, оновлення та управління процесами.
5. У режимі налагодження додає плагін для мосту MCP.
6. При запуску застосунку встановлює заголовок головного вікна, відображаючи назву застосунку та його версію.
7. Запускає застосунок.
