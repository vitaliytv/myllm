# lib.rs

## Огляд

Модуль відповідає за ініціалізацію та запуск основного застосунку. Він налаштовує плагіни для роботи з зовнішніми ресурсами та керування станом і процесами. Запуск відбувається у контексті з відображенням версії застосунку у заголовку.

## Поведінка

1. Запускає застосунок.
2. Ініціалізує плагіни для відкриття зовнішніх ресурсів, роботи з HTTP, агентами, оболонкою та керування станом.
3. Налаштовує обробник викликів для доступу до функціоналу керування системою, проксі, ланцюжків аналізу та моделей агента.
4. Додає плагіни для керування станом вікна та оновлення застосунку у десктопній версії.
5. Додає плагін для керування процесами.
6. У режимі налагодження додає плагін для мосту MCP.
7. При запуску застосунку встановлює заголовок вікна з версією застосунку.
8. Запускає застосунок у контексті.
