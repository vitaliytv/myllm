# lib.rs

## Огляд

Модуль відповідає за запуск застосунку Tauri. Він налаштовує плагіни для роботи з відкриттям, HTTP-запитами та агентом. Модуль надає функціональність для взаємодії з API, керування з'єднанням та історією проксі через публічну функцію `run`.

## Поведінка

1. Запускає застосунок Tauri, ініціалізуючи плагіни для відкриття, HTTP-запитів, агента, а також керуючи станами `OmlxState` та `ProxyRuntime`.
2. Налаштовує обробник викликів для доступу до API, керування з'єднанням, отримання статистики, глобальних налаштувань, а також для запуску, зупинки та очищення історії проксі.
3. Додає плагіни для стану вікна та оновлення, якщо застосунок працює на робочому столі.
4. Додає плагін MCP Bridge, якщо застосунок працює в режимі налагодження.
5. Запускає застосунок Tauri, очікуючи контекст.
