## Огляд

Модуль надає механізми для прямого звернення до адміністративних ендпоінтів зовнішнього `omlx`-сервера (`/admin/api/login`, `/admin/api/stats`, `/admin/api/global-settings`), незалежно від порту локального реверс-проксі. Він виконує аутентифікацію через `/admin/api/login` за API-ключем та зберігає `cookie-сесію`, що необхідна для подальших запитів до `/admin/api/stats` та `/admin/api/global-settings`.

## Поведінка

AdminError — описує можливі помилки, що виникають під час взаємодії з admin API.
Session — містить налаштування для постійного підключення до admin API, включаючи HTTP-клієнт та базовий URL.
AdminState — керує поточним сеансом admin API, що забезпечує безпечний доступ до ним через м'ютекс.
connect — ініціалізує сеанс до admin API, автентифікуючи за API-ключем та зберігаючи сесію.
current_session — повертає поточну активну сесію, якщо вона була встановлена, або вказує на відсутність з'єднання.
stats — отримує статистичні дані з admin API, використовуючи активну сесію.
global_settings — отримує загальні налаштування з admin API, використовуючи активну сесію.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- За певних помилок повертає порожнє значення (напр. `null`) замість винятку.
