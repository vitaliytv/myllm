# config.rs

## Огляд

Модуль визначає та завантажує конфігурацію headless-сервісу. Усі параметри конфігурації зчитуються виключно зі змінних середовища. Функція `from_env` забезпечує отримання конфігурації, де дефолтні значення відповідають попередній логіці. Публічна функція `Config` надає доступ до завантажених налаштувань. Модуль є read-only: він не виконує записів у файлову систему чи бази даних. При зчитуванні параметрів, таких як адреса справжнього omlx-сервера (наприклад, http://127.0.0.1:8000), реалізовано механізм перехоплення помилок (fail-safe), що запобігає виникненню винятків на рівні системи.

## Поведінка

Config — Структура, що зберігає налаштування сервісу, включаючи адресу справжнього omlx-сервера, порт локального проксі, API-ключ для admin-сесії та директорію стору.
from_env — Створює екземпляр Config, зчитуючи значення з змінних середовища, використовуючи дефолтні значення, якщо змінна відсутня.

## Публічний API

Config — зберігає налаштування системи.
from_env — завантажує налаштування з змінних середовища, використовуючи задані значення за замовчуванням, якщо змінна відсутня.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
