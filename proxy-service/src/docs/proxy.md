## Огляд

Сервіс виступає як зворотний проксі для трафіку `/v1/*` до основного omlx-сервера, перехоплюючи запити наприклад до <http://127.0.0.1:{bound_port}/v1/chat/completions>. Паралельно з пересиланням запиту на upstream, проксі стрімить копію в лог, що дозволяє клієнтам бачити повну історію взаємодії в реальному часі. Локальний адміністративний API за шляхом `/_proxy/*` надає лише поточний стан черги. Історія запитів зберігається у `requests.jsonl` і доступна через `/_proxy/history` (GET/DELETE). Сервіс перехоплює мережеві помилки (fail-safe) і не кидає винятків назовні, повертаючи порожнє значення замість винятку у разі певних збоїв.

## Поведінка

Поведінка:
ProxyError описує можливі помилки, що виникають у проксі-сервісі, такі як помилки введення/виведення або невдала прив'язка до порту.
RequestLogEntry містить структурований запис усіх HTTP-запитів, що проходять через проксі-сервіс, включаючи метадані про запит та відповідь.
AppState зберігає спільний стан проксі-сервісу, включаючи клієнт для зв'язку з upstream, шлях до логу та стан адміністративного підключення.
bind ініціалізує TCP-слухач, створює роутер Axum та повертає конфігурацію для запуску проксі-сервісу, визначаючи фактичний порт, на якому працює сервіс.
maybe_auto_connect_admin намагається автоматично встановити сесію для адміністративного API, використовуючи API-ключ з конфігурації, якщо такий доступний.

## Публічний API

ProxyError — Повідомляє про помилку під час перенаправлення запиту.
RequestLogEntry — Записує інформацію про кожен виконаний запит.
AppState — Централізовано зберігає спільні дані для всіх обробників API (включаючи форвардинг та адміністративні ендпоінти).
bind — Запускає мережевий слухач на вказаному порту та повертає готовий до використання маршрутизатор, який керує трафіком.
maybe_auto_connect_admin — При спробі запуску автоматично намагається підключити адміністративну сесію, якщо є ключ API; це спрощення UX без зупинення роботи основного сервісу.

## Гарантії поведінки

- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- За певних помилок повертає порожнє значення (напр. `null`) замість винятку.
