# proxy.rs

## Огляд

Сервіс виступає як зворотний проксі для трафіку `/v1/*` до основного omlx-сервера, перехоплюючи запити наприклад до http://127.0.0.1:{bound_port}/v1/chat/completions. Паралельно з пересиланням запиту на upstream, проксі стрімить копію в лог, що дозволяє клієнтам бачити повну історію взаємодії в реальному часі. Локальний адміністративний API за шляхом `/_proxy/*` надає лише поточний стан черги. Історія запитів зберігається у `requests.jsonl` і доступна через `/_proxy/history` (GET/DELETE). Сервіс перехоплює мережеві помилки (fail-safe) і не кидає винятків назовні, повертаючи порожнє значення замість винятку у разі певних збоїв.

## Поведінка

ProxyError описує можливі помилки, що виникають під час роботи проксі-сервісу, такі як помилки введення/виведення або проблеми з прив'язкою до порту.
RequestLogEntry описує структуру даних, що містить повну інформацію про кожен запит, який проходить через проксі, включаючи метадані, тіло запиту та текст відповіді.
AppState зберігає спільний стан для всіх хендлерів проксі, включаючи клієнт для зв'язку з upstream, шлях до логу, наступний ідентифікатор запису та стан адміністративного підключення.
bind створює TCP-listener, ініціалізує спільний стан та конфігурує маршрутизатор Axum, повертаючи фактичний порт, лістенер та маршрутизатор.
maybe_auto_connect_admin намагається автоматично підключити сесію адміністратора до upstream-сервера, якщо надано API-ключ у конфігурації.

## Публічний API

ProxyError — Повідомляє про помилку при спробі з'єднатися з проксі-сервером.
RequestLogEntry — Зберігає інформацію про кожен отриманий запит для логування.
AppState — Містить спільні дані, доступні всім обробникам запитів (як для проксі-форвардингу, так і для адмін-інтерфейсу `/_proxy/*`).
bind — Запускає мережевий слухач на заданому порту та повертає готовий маршрутизатор для запуску сервісу.
maybe_auto_connect_admin — Автоматично ініціює сесію адміністратора при запуску, якщо надано ключ API, забезпечуючи миттєвий доступ до адмін-панелі.

## Гарантії поведінки

- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
- За певних помилок повертає порожнє значення (напр. `null`) замість винятку.
