# main.rs

## Огляд

Цей модуль реалізує безінтерфейсний (headless) зворотний проксі omlx для застосунку myllm. Він зчитує конфігурацію виключно зі змінних середовища. Сервіс слухає на локальному хості, виконуючи форвардинг запитів до вказаного upstream, застосовуючи компресію та керуючи історією взаємодій. Компонент працює як персистентний процес на macOS через `launchd` без графічного інтерфейсу. Він не здійснює запису у файлову систему чи бази даних.

## Поведінка

1. Завантажує конфігурацію з змінних середовища.
2. Виводить інформацію про базовий URL вихідного сервера та каталог даних.
3. Створює та прив'язує проксі-сервіс, використовуючи конфігурацію.
4. У разі невдачі прив'язки проксі-сервісу, виводить фатальне повідомлення та завершує роботу з кодом 1.
5. Виводить повідомлення про початок прослуховування на локальному хості та порту.
6. Ініціює автоматичне підключення адміністративного інтерфейсу, використовуючи конфігурацію та поточний стан.
7. Запускає сервер, який слухає на прив'язаному сокеті.
8. У разі помилки під час обслуговування, виводить повідомлення про помилку обслуговування та завершує роботу з кодом 1.

## Гарантії поведінки

- Read-only: не виконує операцій запису (ФС/БД).
- Перехоплює помилки і не пропускає винятків назовні (fail-safe).
